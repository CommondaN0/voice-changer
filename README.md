# Voice Changer Pro 🎙️

Современная программа для изменения голоса в реальном времени на Python (PySide6 + sounddevice + DSP).

## Основные возможности

* **Изменение голоса в реальном времени**: сверхнизкая задержка (~11–23 мс) для комфортной игры и общения в Discord/Telegram.
* **Встроенный аудиокабель (1-клик)**: оригинальные подписанные драйверы включены в проект — никаких сторонних сайтов и ручных установок.
* **Готовые пресеты**:
  * Женский (Естественный)
  * Женский (Высокий / Аниме)
  * Мужской (Баритон)
  * Мужской (Глубокий бас)
  * Робот (Ring Modulation)
  * Рация / Walkie-Talkie
  * Космическое Эхо
  * Оригинал (Чистый голос)
* **Быстрая подстройка**: регуляторы Тональности (Pitch), Форманты/Окраса (Timbre) и Громкости.
* **Вкладка «Для продвинутых»**:
  * Ползунки Pitch Shift (-12 до +12 полутонов) и Formant Shift (0.6x до 1.5x)
  * 3-полосный эквалайзер (Low, Mid, High)
  * Эффект робота с регулировкой несущей частоты
  * Эхо / Задержка с обратной связью (Feedback)
  * Дисторшн / Перегруз
  * Шумоподавление (Noise Gate) с регулировкой порога
* **Две темы оформления**: быстрое переключение между современной Тёмной (Dark) и чистой Светлой (Light) темами.
* **Индикаторы звука (VU-Meters)**: визуализация входящего уровня с микрофона и уровня обработанного голоса.
* **Мониторинг («Слышать себя»)**: возможность слышать изменённый голос в своих наушниках параллельно с выводом в игру (кнопка «🎧 ТЕСТ»).
* **Системный трей**: сворачивание в трей при закрытии/минимизации с быстрым контекстным меню ПКМ (Вкл/Выкл, Настройки, Перезапуск, Выход).
* **Проверка прав администратора**: обнаружение и мягкое предложение перезапуска с правами администратора через UAC.

## Установка и запуск

### 1. Создание виртуального окружения
Откройте терминал (PowerShell или CMD) в папке проекта и выполните команду:

```powershell
python -m venv .venv
```

### 2. Активация окружения

* **В PowerShell**:
  ```powershell
  .\.venv\Scripts\Activate.ps1
  ```
  *(Если появится сообщение об ограничении выполнения скриптов, выполните команду `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` и повторите активацию)*

* **В командной строке (CMD)**:
  ```cmd
  .\.venv\Scripts\activate.bat
  ```

### 3. Установка зависимостей
При активном виртуальном окружении установите необходимые пакеты:

```powershell
pip install -r requirements.txt
```

---

### Запуск программы

* **Быстрый запуск**: дважды кликните по файлу [run.bat](run.bat) (скрипт автоматически использует Python из папки `.venv`).
* **Запуск из терминала (при активном окружении)**:
  ```powershell
  python main.py
  ```
* **Прямой запуск из терминала без ручной активации**:
  ```powershell
  .\.venv\Scripts\python.exe main.py
  ```

## Как настроить для Discord и онлайн-игр

1. **Активация кабеля**: если кабель ещё не установлен, при первом запуске нажмите кнопку **«⚡ Активировать виртуальный кабель (1 клик)»**. Программа тихо установит входящий в комплект подписанный драйвер.
2. В программе откройте кнопку **«⚙️ Настройки»**:
   * В поле **«Микрофон (Вход)»** выберите ваш физический микрофон.
   * В поле **«Вывод (Virtual Cable / Discord)»** автоматически выберется **CABLE Input (VB-Audio Virtual Cable)**.
   * В поле **«Мониторинг (Наушники)»** выберите ваши наушники (для проверки звука через кнопку «🎧 ТЕСТ»).
3. В настройках **Discord**, **Telegram** или игры:
   * Устройство ввода (Микрофон) -> выберите **CABLE Output (VB-Audio Virtual Cable)**.
   * Готово! Все участники голосового чата будут слышать ваш измененный голос.
